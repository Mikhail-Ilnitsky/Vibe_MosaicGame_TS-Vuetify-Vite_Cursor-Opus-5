# Контекст проекта «Игра-мозаика»

Адаптивная браузерная игра-мозаика: картинка из галереи делится на квадратные фрагменты, игрок
возвращает их на места. Чистый фронтенд (SPA), без бэкенда, базы данных и роутера — три экрана
(галерея → выбор сложности → игра) переключаются состоянием в `src/App.vue`.

Техническое задание, по которому сгенерирована исходная версия: [`prompts/INITIAL.md`](../prompts/INITIAL.md).

## Стек

- Vue 3 (только Composition API, `<script setup lang="ts">`; Options API не используется)
- TypeScript 5 (`strict`, отдельные `tsconfig.app.json` / `tsconfig.node.json`)
- Vuetify 3 (компоненты импортируются явно в `src/plugins/vuetify.ts`, без иконочных шрифтов)
- Vite 8 (`@vitejs/plugin-vue`)

Весь код приложения лежит в `src/`; конфиги сборки и CI — в корне и в `.github/`.

## Ключевые решения

### Сетка (`src/utils/grid.ts`)

`computeGrid(width, height, minParts)`: меньшая сторона всегда делится на `minParts` (5…11),
`tileSize = floor(меньшая / minParts)`, по большей стороне берётся `floor(большая / tileSize)` целых
фрагментов. Остаток исходника обрезается, сетка центрируется на картинке (`cropWidth`/`cropHeight`).
Проверка по ТЗ для 1000×700: 5 → 7×5 по 140 px, 6 → 8×6 по 116 px, 7 → 10×7 по 100 px.

Натуральные размеры картинки нужны до нарезки, их отдаёт `useImageMeta` (загрузка через `new Image()`),
поэтому экран сложности показывает варианты только после загрузки.

### Фрагменты на CSS (`src/components/PuzzleBoard.vue`)

Картинка не режется физически: каждый фрагмент — `<div>` с `background-image` на весь файл,
`background-size: cols*100% rows*100%` и `background-position: (col/(cols-1))*100% (row/(rows-1))*100%`
(0% при одной колонке или строке). Эти три свойства навсегда привязаны к фрагменту; перемешивание
меняет только его позицию на поле. Фрагменты позиционированы абсолютно и двигаются через
`transform: translate3d(...)`, поэтому обмены анимируются, а перетаскиваемый фрагмент поднимается
над остальными (`z-index`, тень, `scale`).

### Размер поля (`src/composables/useBoardSize.ts`)

Раскладка — одна нескроллящаяся колонка (`100dvh`, `.app-screen`), область поля измеряется
`ResizeObserver`. Сторона фрагмента = `floor(min(доступная ширина / cols, доступная высота / rows,
tileSize))`: пазл всегда виден целиком, не растягивается выше масштаба 1:1, целые пиксели дают ровные
разделительные линии. Фиксированных px для отображаемого размера в стилях нет.

### Управление

Только Pointer Events (`pointerdown`/`pointermove`/`pointerup`/`pointercancel`) плюс
`setPointerCapture` и `touch-action: none` — одинаково работает мышью и касанием. Порог drag —
половина стороны фрагмента: смещение меньше порога трактуется как клик (выделение/обмен), больше —
как перетаскивание; цель определяется по координатам указателя внутри поля. Ход = обмен двух
фрагментов, счётчик в `usePuzzle`. Перемешивание — `count` случайных парных обменов для `count`
фрагментов, с гарантией, что стартовая раскладка не собрана.

Победа: все фрагменты на своих местах → сетка мигает жёлтым 500 мс, затем скрывается, и остаётся та
же обрезанная картинка (`background-size: 100% 100%` на элементе размера поля — то же кадрирование,
что у пазла); под мозаикой плавно появляются сообщение и кнопка новой игры (возврат в галерею).
Просмотр оригинала в процессе игры использует тот же элемент поверх поля, поэтому состояние партии
сохраняется.

### i18n (`src/i18n/`)

Свой минимальный слой без внешних зависимостей: реактивная локаль (`ref<Locale>`), словари RU/EN,
типизированные ключи (`MessageKey`) и `t(key, params)` с подстановкой `{name}`. Язык по умолчанию —
RU, если `navigator.language` содержит `ru`, иначе EN; при смене языка обновляются `document.title`
и `<html lang>`. Локализован весь текст интерфейса.

### Стили

Чистый белый фон, много воздуха, тонкие (полупиксельные) линии между фрагментами, крупные кнопки с
большими отступами под касание. Размеры текста и отступов заданы через `clamp()`.

Две контрольные точки для узких экранов. До 599 px шапка и панель игры складываются в колонку:
переключатель языка уходит под название игры, кнопка выхода встаёт по центру над переключателем
оригинала (`flex-direction: column-reverse` у `.game__actions`). До 419 px кнопки растягиваются на
всю ширину, а подписи обрезаются (`text-overflow: ellipsis` у обёртки текста внутри `v-btn`) —
иначе Vuetify-кнопки с `min-width` выталкивают текст за край экрана.
